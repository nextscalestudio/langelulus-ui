# Design System Rule — Perfume E-commerce Site

This design system applies to EVERY page and component in this project.
Do not deviate from it unless explicitly told to override for a specific request.

## Spacing
- Section vertical padding: 120–160px desktop, 60–80px mobile
- Never let content touch viewport edges
- Generous whitespace between all elements — prioritize breathing room over density

## Typography
- Hero/section headline: 56–96px, elegant serif or refined sans-serif
- Subhead: 24–32px
- Body copy: 16–18px
- Maintain consistent font family + weight hierarchy across all pages

## Buttons
- No flat solid-color buttons
- Use soft gradients or ghost/outline variants
- Rounded corners: 8–12px
- Subtle shadow on hover, smooth transition

## Imagery
- Full-bleed, high-resolution photography/video only
- No small icons or thumbnails as primary visuals

## Animation
- Scroll-triggered fade-in/slide-up on all sections, cards, images
- Consistent easing/timing across the whole site

## Navigation
- Wide item spacing, minimal icons
- Hover underline effect
- Sticky/transparent-to-solid on scroll (match homepage behavior)

## Color Palette
- Base: black / white / neutral tones only
- Brand blue = sparing accent only (links, active states, one key CTA)
- Never use brand blue as a large block or section background

## Layout
- Editorial/asymmetric sections preferred (image one side, text other)
- Avoid uniform grid cards where content allows a more editorial treatment

## Section Transitions
- Soft dividers or gradient fades between sections
- No hard color-block breaks

## Responsive
- Mobile keeps the same airy spacing and hierarchy
- Do not default to cramped mobile stacking — preserve whitespace ratio
