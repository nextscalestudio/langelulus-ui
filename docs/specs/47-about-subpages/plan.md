## Key Design Decisions (from research.md)

1. **`/about` is an overview landing** — 5 clickable cards, not a redirect.
2. **Bilingual fields up-front** — `titleVi`/`titleEn` pair on every content object.
3. **Pages render Vietnamese** — until spec 48 (next-intl) wires locale switching.
4. **`AboutPageShell`** — shared server component for hero + max-width wrapper; prevents duplication across 5 sub-pages.
5. **Catalogue PDF** — placeholder `<a>` link, no PDF generation.
6. **Nav labels → all Vietnamese** — done in the same PR as the About dropdown.
